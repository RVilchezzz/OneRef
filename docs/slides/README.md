# Slides

One folder per delivery. Each deck is a set of HTML slide fragments (`project/slides/<id>.html`, fixed
1920×1080 canvas) with `project/deck.json` for the order and fonts. Opening one fragment in a browser shows its
content, not the deck viewer.

| Folder | Delivery | What is inside |
|---|---|---|
| [`delivery_I/`](delivery_I/) | I, Oct 29: project plan | `project/` (14 slides), `slides_content.md` (plain text + speaker notes of every slide), `delivery_I_plan.pptx` (first 9-slide export), `speaker_script_delivery_I.en.md` / `.fr.md` (15-min word-for-word script, jury Q&A) |
| [`delivery_II/`](delivery_II/) | II, Nov 12: preliminary results on dev | `project/` (11 slides), `assets/` (images with sources), `OneRef – Preliminary Results (Delivery II).pdf`, `speaker_script_delivery_II.en.md` / `.fr.md` / `.es.md` (10-min script), `charles_part_delivery_II.fr.md` (Charles's part in detail), `delivery_I_vs_II_comparison.fr.md` (Delivery I announced vs II delivered, FR), `pipeline_run_explained_delivery_II.fr.md` (step-by-step explanation of the 18-image run, FR) |
| [`final/`](final/) | Final, Nov 26 | `slides_content.md`: skeleton of the final deck. `TBD(test)` marks the numbers filled in after the test; the figures come from `scripts/make_figures.py` (`results/figures/`) |

Copies of the Delivery I deck with the script in the speaker notes are in the project folder outside the repo
(`../../../IA025 – Final Project Plan (Delivery I) – notes EN.pptx` / `notes FR.pptx`).

Images derive from MMAD (MVTec AD and MVTec LOCO: CC BY-NC-SA 4.0; VisA: CC BY 4.0; GoodsAD: research use);
each `assets/README.md` lists the source and license of every image.
