Messages between agents are JSON validated with Pydantic; invalid answers are retried once, then count as errors. Code: github.com/RVilchezzz/OneRef

In two weeks the whole workflow became code. Every agent exists, exchanges validated JSON messages and is covered by tests that run without a GPU. The orchestrator runs one model at a time over the whole split, caches every answer and can resume after a Colab disconnect. All agents already ran on real data: the expert on the 835 dev images, and the whole workflow end to end on eighteen images with a small local reader. We also fixed the dev and test splits and wrote a tool that downloads only the images a split needs: 2.1 GB for dev instead of the full 28 GB.
