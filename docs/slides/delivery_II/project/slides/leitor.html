9 images: a working pipeline, not a result

Smoke test on the laptop (RTX 3060, 6 GB): 9 dev images, 1–2 per source; both readers = Qwen3-VL-4B quantized (Ollama); rules-only verifier. The 8B readers run on Colab.

This is the first time the whole multi-agent workflow ran on real MMAD data, today, on the laptop. Nine dev images, one normal and one defective per source, 45 questions. Each agent ran as its own pass and freed the GPU: expert, reader A, reader B, the verifier, which reopened two images it found inconsistent, and the vote. No invalid answers. Object questions are easy, localization is the weak spot, which is exactly where the expert should help once calibrated. With nine images the confidence interval goes from 37 to 82 percent, so this proves the pipeline works, not that it beats anything. The two readers agreed on every question because they were the same small model: that is why the real system uses two different model families.
