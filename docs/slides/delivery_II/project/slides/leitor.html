A small-model smoke test of the core idea, not the B1 baseline: the real readers are the 8B models on Colab. Paired comparison with McNemar.

Before the 8B runs on Colab, we test the core idea on the laptop with the small 4B model: the same questions answered twice, with and without one sentence from the visual expert saying which region differs most. This is a smoke test, not a baseline. If the hint helps here, it supports the design; if not, it tells us early that the hint must be calibrated or given only where the expert is reliable.
