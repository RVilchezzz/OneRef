18 images: a working pipeline, not a result

Smoke test on the laptop (RTX 3060, 6 GB): 18 dev images, 2–4 per source; both readers = Qwen3-VL-4B quantized (Ollama); rules-only verifier. The 8B readers run on Colab.

This is the first time the whole multi-agent workflow ran on real MMAD data, today, on the laptop. Eighteen dev images from all four sources, half normal and half defective, 88 questions. Each agent ran as its own pass and freed the GPU: expert, reader A, reader B, the verifier, which reopened four images it found inconsistent, and the vote. 184 model calls and no invalid answers. Object questions are easy; discrimination and localization are the weak spots, which is exactly where the expert should help once calibrated. With 18 images the confidence interval goes from 54 to 86 percent, so this proves the pipeline works, not that it beats anything. The two readers agreed on 87 of 88 questions because they were the same small model: that is why the real system uses two different model families.
